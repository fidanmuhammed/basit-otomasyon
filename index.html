What I do

I automate ad creative production for online sellers.

Dropshipping lives on testing many creatives quickly. Making each one by hand is slow and expensive. I built a workflow that does the heavy part automatically.

A

The problem

Sellers need a constant stream of fresh video and image ads for each product. Shooting, editing and revising them takes hours per product, or costs money per creative.

B

What I built

An automated workflow. Photos of a product from several angles go in. The workflow submits them to Higgsfield's API, which runs the Seedance model and returns finished video and image ads.

C

What it gives you

Ready-to-test creatives from the photos you already have, so you can try more products and more angles with far less manual work.

Technology

Built on Higgsfield's API and Seedance.

I don't train models. I connect strong existing ones into a workflow a seller can actually use.

H

Higgsfield API

A generative media platform with an API. My workflow uses it to submit generation jobs programmatically and receive the finished video and image files.

S

Seedance

ByteDance's video generation model, accessed through Higgsfield. It takes reference images and instructions and generates short, ad-style clips.

W

Workflow automation

The glue that matters: it takes the uploaded photos, runs the generation, and delivers the results without manual steps in between.
